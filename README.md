# duplicate-cursor

# 🖱️ Cursor Website UI Clone

This project is a frontend **UI clone of the Cursor website**, created using **pure HTML and CSS**.  
The goal was to recreate the overall layout, visual structure, and styling of the original Cursor landing page for practice and learning purposes.

---

## 📌 Sections Recreated

### 🔹 Navigation Bar
- Cursor icon and logo
- Navigation links (Product, Enterprise, Price, Resources)
- Action buttons (Sign in, Download)
- Sticky navbar using `position: sticky`

### 🔹 Hero / Main Content Section
- Headline text introducing Cursor
- Supporting description text
- Primary call-to-action button (Download for macOS)

### 🔹 Visual / Banner Section
- Background banner image
- Foreground main product screenshot
- Image overlay using `position: relative` and `position: absolute`

### 🔹 Footer Section
- Trust statement text
- Company cards (Stripe, OpenAI, NVIDIA, etc.)
- Card-based layout using Flexbox
